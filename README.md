# 퇴직금·연차 계산기 (단일 HTML 웹앱)

대한민국 근로기준법·근로자퇴직급여 보장법 기준의 모바일용 계산기입니다.
`index.html` 파일 **하나만** 올리면 동작합니다(외부 CDN·서버·빌드 없음).

- 배포: GitHub Pages 등 정적 호스팅에 `index.html` 업로드 (파일명 유지)
- 미리보기: `preview-mobile-leave.png`, `preview-mobile-severance.png`, `preview-mobile-form.png`, `preview-mobile-full.png` (390×844 모바일 뷰포트, DPR 3)

## 계산 기준

### 연차 (근로기준법 제60조)
- 1년 미만: 1개월 개근 시 1일, 최대 11일
- 1년 이상: 15일, 3년 차부터 최초 1년 초과 매 2년마다 1일 가산, **총 25일 한도**
- 입사일(기념일) 기준과 회계연도(1월 1일) 기준을 모두 계산하고, 퇴사 정산일수를 나란히 비교
- 회계연도 기준: 매년 1월 1일 부여 / 입사 첫해는 월차 / 다음 해 1월 1일에는 전년도 재직일수 ÷ 365 × 15일(내림)
- 회계연도 기준 퇴사 정산: 당해 부여일수 × (1월 1일~퇴사일 재직일수 ÷ 365), 소수점 이하 버림
- 연차수당: 잔여일수 × 1일 통상임금, 1일 통상임금 = 월 통상임금 ÷ 209 × 8 (주 40시간·1일 8시간)

### 퇴직금 (근로자퇴직급여 보장법 제8조)
- 재직일수: 입사일~퇴사일 초일 산입(당일 포함), **365일 미만이면 미발생**
- 평균임금 산정기간: 퇴사일 포함 직전 3개월(3개월 전 같은 날의 다음 날부터, 월말·윤년 2/29 자동 보정)
- 3개월 임금총액 + 연간 상여금 × 3/12 + 전년도 미사용 연차수당 × 3/12
- 1일 평균임금 = 3개월 임금총액 ÷ 3개월 총일수
- 1일 통상임금 = 월 통상임금 ÷ 209 × 8 (또는 직접 입력)
- **1일 평균임금과 1일 통상임금 중 큰 금액 적용**(근로기준법 제2조 제2항), 적용 근거를 화면에 표시
- 퇴직금 = 적용 1일 임금 × 30 × (재직일수 ÷ 365), 원 미만 절사

## 검증

```bash
node test.js     # 계산 코어 66개 단언 (index.html 안의 코어를 그대로 추출해 검증)
python3 uitest.py  # 실제 Chrome 모바일 뷰포트(390x844) 동작 테스트 41개 항목
```

`test.js`는 `index.html`의 `/* ==CORE-START== */ ~ /* ==CORE-END== */` 블록을 읽어 실행하므로,
브라우저에서 도는 코드와 완전히 같은 코드를 검증합니다.

주요 경계값: 재직 364일/365일, 윤년 2월 29일 포함 3개월, 월말 퇴사(5/31 → 3/1~5/31), 상여·연차수당 3/12 가산,
통상임금 > 평균임금, 1년 미만 11일 상한, 21년차 25일 상한, 회계연도 비례 부여·정산.

`uitest.py`는 로컬 Chrome for Testing(`/workspace/scratch/calc/bin`)과 Playwright가 필요하며,
테스트용 HTTP 서버(`python3 -m http.server`)를 띄웠다가 종료까지 직접 처리합니다.

## 가정과 한계
- 연차는 개근을 가정합니다(결근·입사 1년 미만 80% 미만 출근 등은 반영하지 않음).
- 실업·휴직 등 평균임금 산정 제외기간, 퇴직소득세, 비과세 수당은 반영하지 않습니다.
- 회사 취업규칙의 소수점 처리 규정에 따라 회계연도 기준 정산은 1일 정도 차이가 날 수 있습니다.
